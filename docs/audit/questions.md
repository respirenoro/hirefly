## Gaps found

- No tool or process questions for Azure DevOps Test Plans, Jira versus Azure DevOps, ceremonies, UAT gates, documentation or reporting.
- Few scenarios in each role's own work; no practical-exercise prompts (bug report, backlog ranking, customer update, SQL).
- Nothing on AI use, async writing, recruiter screens, panel and values rounds, illegal questions, take-homes.
- No resume-probing for a generalist: broad title, self-taught skills, defending the 35 percent figure, gap, degree mismatch.
- Data (24) and healthcare (23) under 30. Difficult-interviewer questions thin.
- About 195 intents were one-line fragments; about 35 answer guides were generic.

No true duplicates were found; the similarity flags were different questions.
